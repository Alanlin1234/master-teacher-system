# 名师成片路演夹具

数字人课堂形象和成片管线的完整说明见 `0506/docs/数字人.md`。这里只写这一套固定回放片子。

开启 `VITE_ROADSHOW_USE_MOCK=true` 或后端 `TEACHER_STUDIO_DEMO=1` 后，名师成片四步忽略课题、讲稿和勾选，始终回放下面这些文件。不调用 Duix，也不重新生成。

片子来自已有成片，不是当前仓库里的 Duix 管线跑出来的。当前代码缺少 TTS / 口播容器，也没有 PPT 截图和抠背景步骤，所以没有重跑。

| 文件名 | 用途 |
|---|---|
| `model.mp4` | 第 1 步模特预览。来自中间产物里的模特视频 |
| `merged.mp4` | 第 3 步每一段，以及第 4 步合并，都播这一条。来自指定成片 `56eb3bfa0c25d2cd857ae8194a818d70.mp4` |
| `fallback-replaced.mp4` | 备用口播。`merged.mp4` 缺失时，后端取视频会落到这一条。来自中间产物 `dh_video_4_93e49ddc_replaced.mp4` |
| `manifest.json` | 固定四段讲稿（从《德意志意识形态》教案压缩而来）和上面的文件名 |

讲稿四段是：课题引入、原著定位、核心原理、小结。界面上四段视频地址都指向 `merged.mp4`。

没有放进本目录的中间产物：

- PPT 页截图只有两张约 2.7KB 的小图，不像真实幻灯片，未接入第 1 步。
- 三段 `dh_audio_*.wav`、声音参数 json、用户与历史 json。历史里含密码哈希，不复制到前端。
- 讲稿原文在生成时只留在内存，压缩包里没有分段 JSON；本目录用的是从教案抽出的四段口播。

mp4 不进 git，只放本机。缺文件时把对应片子按上表文件名拷回本目录。
